# NUA Protocol — Konohagakure assets

Arquivos separados para uso no frontend PHDEV.

- cards/: 10 artes individuais, recortadas da prancha gerada, sem texto ou botões. Aproximadamente 883 × 173 px; use como fundo horizontal.
- backgrounds/: paisagem original gerada, variante escura e desfocada.
- banners/: recortes decorativos sem texto; Pain extraído do mockup aprovado, não uma ilustração nova em alta resolução.
- effects/: folhas e brasas vetoriais com fundo transparente.
- icons/: vetores estilizados produzidos para o pacote, não arquivos oficiais nem reproduções exatas dos símbolos.
- patterns/: padrões decorativos vetoriais estilizados.
- references/: mockup aprovado, somente referência visual (não usar como interface).

Use CSS/React para textos, status e controles reais. PAIN é mensagem visual, não protocolo. Não incluir Kage Bunshin. Os personagens e referências pertencem aos respectivos titulares; a autorização de uso comercial não foi verificada.
