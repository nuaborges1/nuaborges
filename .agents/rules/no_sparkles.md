# Regra do Projeto: Proibição Estrita de Sparkles

1. NUNCA importar ou renderizar o ícone `Sparkles` do Lucide ou qualquer outro pacote neste projeto.
2. Nua Borges possui identidade minimalista, luxuosa e autoral. Ícones de faísca/estrelinha infantilizam o design e quebram a linguagem visual da marca.
3. Use ícones conceituais:
   - Para Personalizados: `Camera`, `Film`, `Sliders`, `Crown` ou `Wand2`
   - Para VIP/Exclusivo: `Crown`, `Gem` ou `HeartOutlineIcon`
   - Para Destaques: `Flame`, `Zap`, `CheckCircle2` ou `Star`
