# Admin Geral — Standalone Prototype

Este diretório contém o protótipo estático independente (`index.html`) da Central de Monitoramento e Administração Geral.

* Utilizado como referência visual e teste isolado sem dependência de runtime do Next.js.
* O painel oficial e reativo em produção é compilado a partir de `app/admingeral/page.tsx` e dos componentes em `components/admingeral/`.
